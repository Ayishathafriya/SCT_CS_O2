# SCT_CS_O2
This project is a **lightweight image encryption tool** built in Python that demonstrates how cryptographic concepts can be applied to digital images using pixel manipulation. By performing operations such as pixel swapping and mathematical transformations, the tool obscures image data in a reversible way. It is designed as an educational resource for students and professionals exploring the intersection of **cybersecurity** and **image processing**.

The tool emphasizes simplicity, reproducibility, and clarity. It is not intended for production‑grade security but rather as a foundation for learning and experimentation. Users can extend the project by integrating more advanced algorithms or combining it with existing cryptographic libraries.

Features
- **Pixel Swapping**: Randomized rearrangement of pixel values to distort image structure.  
- **Mathematical Operations**: Apply transformations such as addition, subtraction, or XOR to pixel intensities.  
- **Encryption & Decryption**: Fully reversible process to restore the original image.  
- **Key‑Based Control**: User‑defined keys ensure consistent encryption and decryption.  
- **Minimal Dependencies**: Requires only Pillow and NumPy, making it easy to set up.  

##Technology Stack
- **Language**: Python 3.x  
- **Libraries**:  
  - `Pillow` – image input/output  
  - `NumPy` – efficient pixel array manipulation  

##Workflow
1. Load the image into a pixel matrix.  
2. Apply encryption operations (swap or mathematical transformation).  
3. Save the encrypted output.  
4. Reverse the process using the same key to decrypt.  
##Applications
- Academic demonstrations of **cryptography** concepts  
- Introductory projects in **cybersecurity** courses  
- Lightweight experiments in **image obfuscation** and **data security**
